AJIT MENE Admin (Demo Mode)
Demo mode. This panel edits project data only inside your current browser (localStorage) — it does not write to data/projects.json on disk and provides no real authentication or security. It's here so you can preview the add/edit/delete/reorder workflow. For a real, secure, multi-device admin experience with a proper database, deploy the Django + DRF + MySQL backend included in /backend (see the project README) and this panel can be pointed at that API instead.
